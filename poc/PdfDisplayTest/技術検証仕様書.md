# 最終目標

本アプリは、PDFを画像として編集するアプリではない。

目的は、CAD・Office等から出力されたPDFを対象とし、

- PDF表示
- PDF標準注釈
- PDF文字情報取得
- PDFコメントへの独自情報保存

を組み合わせて、Acrobat Readerと互換性のあるPDF図面チェックアプリを開発する。

画面表示は画像レンダリングを利用するが、
保存されるデータは可能な限りPDF標準仕様に従う。

# PoC-05 文字座標取得

## 目的

PDF内の文字ごとの座標を取得できることを確認する。

## 使用ライブラリ

- PDFiumSharp

## 使用API

```csharp
PDFium.FPDFText_GetCharBox(...)
```

## 検証内容

- 全文字の座標取得
- Left
- Right
- Bottom
- Top
- 文字数分すべて取得できること

## 結果

✅ 成功

96文字すべての座標取得に成功。

取得例

```
0:
L=562.88
R=570.08
B=19.99
T=27.08
```

## 検証中に発生した問題

### エラー

```
Cannot marshal return value
```

当初は `FPDFText_GetCharBox()` が原因と考えたが、
調査の結果、原因は別箇所であることが判明。

以下も検証した。

- 自作 DllImport
- IntPtr による呼び出し
- Reflection によるアクセス

しかし最終的には不要だった。

## 最終結論

PDFiumSharp が提供している

```csharp
PDFium.FPDFText_GetCharBox(...)
```

をそのまま使用すれば正常に動作することを確認。

追加ライブラリや PdfiumCore への移行は不要。

## 調査結果

### Gemini

- GetCharBox は未実装と回答
- PdfiumCore への移行を推奨

→ 公式ソースとは一致しなかった。

### Claude

PDFiumSharp の公式ソースを確認。

`PDFium.tt`

に

```csharp
public static bool FPDFText_GetCharBox(...)
```

が定義されていることを確認。

こちらの情報が正しかった。

## 成果

現在確認済み

- ✅ PDF表示
- ✅ PDF標準注釈追加
- ✅ PDF注釈読込
- ✅ PDF文字抽出
- ✅ PDF文字座標取得

## コミット

```

```
