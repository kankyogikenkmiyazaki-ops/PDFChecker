# PoC-07 描画レイヤー

## 目的

PDF画像の上にWPF Canvasを重ね、PDF表示範囲内へフリーハンド描画できることを確認する。

## 使用技術

- WPF Grid
- WPF Canvas
- Polyline
- PDFiumSharpで生成したBMP画像

## 検証内容

- PDF画像の上へCanvasを重ねる
- マウスドラッグによるフリーハンド描画
- 複数ストローク描画
- PDF表示範囲外への描画制限
- ウィンドウサイズ変更時の表示追従
- 縦向きPDF・横向きPDFの表示比率確認

## 現在の結果

✅ Canvas重ね表示成功

✅ 赤色のフリーハンド描画成功

✅ 複数ストローク描画成功

✅ PDFページ範囲内だけ描画可能

## 実装構成

```text
PdfViewport
└── PdfPageHost
    ├── PdfImage
    └── DrawingCanvas
```

`PdfImage` と `DrawingCanvas` を同じ `PdfPageHost` 内へ配置し、表示サイズを一致させることで、灰色の余白部分には描画できないようにした。

## 検証中に発生した問題

### PDFを開いた直後だけ表示サイズが崩れる

PDFを開いた直後、A4縦PDFが表示領域いっぱいに引き伸ばされる問題が発生した。

ウィンドウサイズを変更すると正常な比率へ戻った。

### 原因

PDF画像設定直後は、`PdfViewport.ActualWidth` と `ActualHeight` がまだ確定していない場合があり、不正確なサイズで `PdfPageHost` の大きさを計算していた。

### 対応

`PdfImage.Source` 設定後に、レイアウト確定後のタイミングで表示サイズを更新する。

```csharp
Dispatcher.BeginInvoke(
    DispatcherPriority.Loaded,
    new Action(UpdatePdfPageDisplaySize));
```

これにより、縦向きPDFは開いた直後から正しい比率で表示できるようになった。

## 横向きPDFで文字が変形する問題

横向きPDFでは、ページ全体は横向きで表示されたが、文字が横方向へ引き伸ばされる問題が発生した。

### 原因

表示サイズの計算にPDF内部のページサイズ

- `_pdfPageWidth`
- `_pdfPageHeight`

を使用していた一方で、実際に表示しているBMP画像はPDFの回転を反映した縦横になっていた。

そのため、PDF内部座標の縦横比とBMP画像の縦横比が一致せず、`Stretch="Fill"` により画像が変形していた。

### 対応方針

画面表示サイズは、PDF内部ページサイズではなく、実際に表示するBMP画像のサイズを使用する。

```csharp
double imageWidth = bitmap.PixelWidth;
double imageHeight = bitmap.PixelHeight;
```

役割を以下のように分離する。

```text
_pdfPageWidth / _pdfPageHeight
    → PDF内部座標変換用

bitmap.PixelWidth / bitmap.PixelHeight
    → 画面表示サイズ計算用
```

また、`PdfImage` は縦横比を保つため次の設定とする。

```xml
<Image x:Name="PdfImage"
       Stretch="Uniform" />
```

## PDFを開き直しても表示が変わらない問題

PDF選択ダイアログでは別のPDFを選択できるが、画面上の表示が前のPDFから変わらない問題が発生した。

### 原因

BMPの出力先が同じファイル名で、`BitmapImage.UriSource` が以前の画像をキャッシュしていた。

### 対応

`UriSource` を使用せず、`FileStream` と `StreamSource` でBMPを毎回読み込むように変更した。

```csharp
BitmapImage image;

using (var stream = new FileStream(
    bmpPath,
    FileMode.Open,
    FileAccess.Read,
    FileShare.ReadWrite))
{
    image = new BitmapImage();
    image.BeginInit();
    image.CacheOption = BitmapCacheOption.OnLoad;
    image.StreamSource = stream;
    image.EndInit();
    image.Freeze();
}
```

これにより、同じBMPファイル名を再利用してもPDFを正常に切り替えられることを確認した。
