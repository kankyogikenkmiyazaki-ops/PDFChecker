# PDF編集ライブラリ / PDF朱書きソフト 基本設計書

## 1. 目的

本プロジェクトは、Windows向けの **PDF編集基盤**
を作成することを目的とする。

最初のバージョンでは「PDFを確認し、朱書き・チェックを行う」ことに機能を限定する。

将来的には本ライブラリを利用して、

-   PDF図面チェックアプリ
-   PDF比較
-   AIチェック
-   集計機能
-   OCR
-   業務向けPDFツール

へ発展させる。

------------------------------------------------------------------------

# 2. 開発方針

-   開発言語：C#
-   UI：WPF (.NET)
-   Windows専用アプリ
-   インストール型アプリを前提
-   PDF編集ライブラリとして再利用可能な構成を目指す
-   最初から過度な分割は行わず、小さく育てる

## 注釈コメント

PDF注釈には最低限の情報のみ保存する。

項目

-   type
-   color
-   diameter

例

``` json
{
  "type":"check",
  "color":5,
  "diameter":"150"
}
```

# 8. 最終目標

本プロジェクトは単なるPDF編集ソフトではなく、

**将来的にPDF図面チェックアプリの土台となるPDF編集ライブラリ**

として育てることを目的とする。

Ver1では小さく完成させ、 完成後に必要な機能を順次追加していく。

このプロジェクトの方針としては

Ver1に必要か？

Yes → 実装する
No → 設計だけして保留
